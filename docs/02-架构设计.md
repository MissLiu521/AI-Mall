# AI Mall — 架构设计

## 1. 总体架构

```
┌────────────────────────────────────────────────────────────┐
│  前端 SPA (Vue3 + TS + Vite)                                │
│  /shop/*  C端商城        /admin/*  B端后台                  │
│  ─────────────────────────────────────────────              │
│  api/ 统一请求层  ·  AI 助手悬浮组件  ·  设计 Token 层       │
└───────────────────────┬────────────────────────────────────┘
                        │ fetch / JWT
┌───────────────────────▼────────────────────────────────────┐
│  Express 应用 (server/src)                                  │
│  ─────────────────────────────────────────────              │
│  middleware: auth / role / error / requestId                 │
│  routes:  auth · products · cart · orders · admin · ai       │
│  services: 业务逻辑（唯一可写 DB 的地方）                    │
│  ai/:  gateway · agent-runtime · tools · prompts · fallback  │
└───────────────────────┬────────────────────────────────────┘
                        │ better-sqlite3 同步驱动
┌───────────────────────▼────────────────────────────────────┐
│  SQLite (data/mall.db)  schema + seed 启动自动迁移          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 分层约定

| 层 | 职责 | 禁止 |
| --- | --- | --- |
| routes | 解析入参、鉴权、返回统一响应 | 写业务逻辑、拼 SQL |
| services | 业务规则、事务、校验 | 感知 req/res |
| db | schema、连接、迁移、seed | 业务判断 |
| ai | 模型调用、工具执行、降级 | 直接返回裸文本给前端（统一走 envelope） |

## 3. 数据模型

```sql
users(id, email, password_hash, name, role, created_at)
products(id, title, subtitle, description, price_cents, compare_at_cents,
         stock, category, tags, images, status, rating, sales, created_at)
cart_items(id, user_id, product_id, qty, created_at)          -- UNIQUE(user_id, product_id)
orders(id, order_no, user_id, status, subtotal_cents, discount_cents,
       total_cents, address, remark, ai_assisted, created_at, paid_at, shipped_at)
order_items(id, order_id, product_id, title, price_cents, qty)
refunds(id, order_id, user_id, reason, status, amount_cents, created_at, decided_at)
ai_conversations(id, user_id, scene, title, mode, created_at)
ai_messages(id, conversation_id, role, content, tool_calls, latency_ms, created_at)
ai_config(key, value)          -- 单行 KV：model/baseUrl/temperature/persona
kb_entries(id, question, answer, tags, created_at)   -- 客服知识库
```

订单状态机：

```
pending_payment → paid → shipped → completed
        ↓            ↓        ↓
     cancelled   refunding → refunded
```

## 5. Agent Runtime 设计

```
runAgent({scene, messages, userId})
  1. 组装 system prompt（人设 + 场景 + 可用工具 schema）
  2. loop (max 4 turns):
       resp = gateway.chat(messages, tools)
       if resp.tool_calls: 逐个执行 → 结果作为 tool 消息回灌 → continue
       else: 返回最终文本
  3. 记录 mode(local/remote)、latency、tool 轨迹
```

- 工具执行有白名单 + 权限校验（userId 只能查自己的订单）。
- 工具有超时（3s）与结果截断（4KB），避免上下文爆炸。
- 真模型不可用时，fallback 引擎用同一套意图 + 工具直接产出结果，保证体验一致。

## 6. 安全

- 密码 bcrypt(10)，不返回 hash
- JWT HS256，8h 过期，密钥来自 env
- 所有 SQL 走 prepared statement
- 前端所有动态文本用 Vue 插值（默认转义），不用 v-html
- 管理接口二次校验 role
- 下单幂等：`X-Idempotency-Key` + 唯一索引
