### 7.4 小程序端结论与风险

- 两端产物结构完整：`app.json` 9 页面 + tabBar 齐全，构建零报错。
- 未发现浏览器专属 API（window/document/localStorage）泄漏进小程序代码；网络层全部走 `uni.request`，AI 接口为普通 POST 非流式，兼容。
- 已知限制（非缺陷）：
  1. `appid` 为空/`touristappid`，正式发布前需在 `src/manifest.json` 填写；
  2. API 基址为局域网 HTTP（构建时注入），真机预览需手机与电脑同网；生产必须 HTTPS + 域名白名单；
  3. 缺 `sitemap.json`，微信工具会提示一条非致命警告；
  4. 小程序运行时行为需在微信/支付宝开发者工具中人工确认，本环境无法自动化（工具需图形界面且要求开启服务端口）。
- 移动端未接入 4 项体验改进（可解释搜索、信息透明化、退款时间轴、AI 能力边界），为最大的端间差异，见 6.5 遗留。
