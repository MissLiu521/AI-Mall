# AI Mall — UI 设计系统

## 1. 设计语言

**关键词**：冷静、克制、有智感（Calm Intelligence）

电商界面信息密度高，容易吵。AI 元素如果做成"花哨的渐变+发光"，会立刻显得廉价且像玩具。
所以本系统走**冷灰底 + 单一强调色 + 极轻描边**的路线，把"AI"从视觉噪音变成**可用的工具感**：

- 主体用中性灰阶，让商品图成为唯一的高饱和区域；
- AI 相关元素（助手入口、智能推荐位、工具调用轨迹）统一用 **蓝紫单一强调色**，形成可识别的"智力标签"；
- 圆角克制（8/12/16 三档），阴影只用两层，避免卡片漂浮感过强。

| `--text-3` | `#8D94A6` | 占位、辅助 |

## 3. 字体与字号

- 中文：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- 数字：`ui-monospace, "SF Mono", Consolas` （用于价格、订单号，等宽更整齐）

| 级别 | 字号/行高 | 用途 |
| --- | --- | --- |
| Display | 32/1.2 600 | 首页大标题 |
| H1 | 22/1.35 600 | 页面标题 |
| H2 | 17/1.4 600 | 区块标题 |
| Body | 14/1.6 400 | 正文 |
| Small | 13/1.5 400 | 辅助 |
| Caption | 12/1.4 400 | 标签、时间 |

## 4. 间距与布局

- 基础栅格 4px，常用 8/12/16/20/24/32/40
- 容器最大宽 1200px，两侧 padding 24px
- 卡片圆角 12px，按钮 8px，胶囊 999px
- 阴影：`0 1px 2px rgba(16,24,40,.06)` / `0 8px 24px rgba(16,24,40,.08)`

## 5. 组件规范

| 组件 | 规格 |
| --- | --- |
| Button | 高 36（sm 30 / lg 44）；primary 实心、secondary 描边、ghost 无底；禁用态 opacity .45 |
| Input | 高 36，1px 描边，focus 时 primary 描边 + 3px 光晕 |
| Card | surface 底 + line 描边，hover 抬升 1px |
| Badge | 高 20，圆角 999，语义色浅底 + 同色深字 |
| Table | 表头 `--surface-2`，行高 52，分隔线 1px |
| Drawer | 右侧滑出，宽 420，圆角左侧 16 |
| AI 气泡 | 左侧 AI 用 `--ai-soft` + 左上角 4px 圆角刻意的"缺口"；用户侧 primary 实心 |

## 6. AI 元素的视觉规则

1. **AI 入口**：右下悬浮球，`--ai` 描边 + 白底 + 微光晕，不呼吸闪烁（避免干扰）。
2. **AI 消息**：统一带一个 14px 的 AI 标记徽章，与用户消息明确区分。
3. **工具调用轨迹**：折叠式，默认收起，展开显示 `工具名 + 关键参数 + 耗时`，用等宽字体。这是"可信感"的来源——让用户看到 AI 真的去查了。
4. **智能推荐位**：卡片左上角一枚 `AI 精选` 胶囊，仅此一处使用 `--ai` 浅底。
5. **本地降级模式**：顶部显示 `本地引擎` 描边徽章，绝不用"AI 生成中"掩盖。

## 8. 响应式

- ≥1200：4 列商品，侧栏展开
- 768–1199：3 列，侧栏折叠为图标
- <768：2 列，导航收起，AI 抽屉全屏

## 9. 可访问性

- 文本对比度 ≥ 4.5:1
- 所有交互元素有 `:focus-visible` 描边
- 图标按钮带 `aria-label`
- 动效 ≤ 200ms，尊重 `prefers-reduced-motion`
