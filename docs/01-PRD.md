# AI Mall — 产品需求文档（PRD）

> 版本 v1.0 ｜ B/C 一体化 AI 商城系统

## 1. 产品定位

一套代码同时服务两类用户：

| 端 | 用户 | 核心诉求 |
| --- | --- | --- |
| C 端商城 | 消费者 | 快速找到想要的商品、被理解、被推荐、下单顺畅、售后有问必答 |
| B 端后台 | 商家/运营/客服主管 | 管商品、看数据、管订单、配置 AI 能力、看 AI 会话质量 |

差异点不是"加了聊天框"，而是 **AI 作为贯穿全链路的执行层**：

- 售前：AI 导购（理解模糊需求 → 精准选品）
- 售中：AI 购物车助手（凑单、优惠、库存校验）
- 售后：AI 客服（订单查询、退换货、物流），可**调用工具真实操作**
- 商家侧：AI 运营智能体（生成商品文案、分析滞销、生成营销活动）

## 2. 角色与权限

| 角色 | 权限 |
| --- | --- |
| guest | 浏览商品、搜索、与 AI 导购对话（不带订单上下文） |
| customer | 下单、查看自己订单、售后、AI 客服带订单上下文 |
| merchant | 商品 CRUD、订单处理、AI 配置、数据看板、查看全部 AI 会话 |

## 3. 核心流程

### 3.1 C 端主流程

```
首页/搜索 → 商品详情 → 加购 → 结算 → 支付(Mock) → 我的订单 → 售后(可选, AI 协助)
                                    ↑
                          AI 导购/AI 客服 全程悬浮可唤起
```

### 3.2 AI 客服流程（工具调用闭环）

```
用户提问
  → 意图识别（订单/物流/退换/商品/闲聊/投诉）
  → 需要事实性数据？ → 调用工具（get_order / list_my_orders / get_product / check_return_eligibility）
  → 基于工具真实返回生成回答（禁止编造）
  → 写入会话记录 + 满意度埋点
```

### 3.3 B 端运营智能体流程

```
商家输入目标（如"帮我给滞销商品写5条卖点"）
  → 智能体读取库内真实商品数据
  → 规划步骤（分析 → 生成 → 结构化输出）
  → 返回可一键应用的结果（写回商品描述）
```

## 5. AI 能力定义

### 5.1 三个 AI 角色

1. **导购助手（Shopping Copilot）**：C 端。目标为促成合适的交易，可查商品、比价、推荐。
2. **客服 Agent（Support Agent）**：C 端。目标为解决问题，可查订单、发起退款申请。
3. **运营智能体（Ops Agent）**：B 端。目标为产出运营资产，可读数据、写商品。

### 5.2 工具（Function Calling）清单

| 工具 | 作用 | 归属 |
| --- | --- | --- |
| `search_products` | 按语义/关键词搜品 | 导购 / 客服 |
| `get_product_detail` | 商品详情 | 导购 / 客服 |
| `get_my_orders` | 我的订单列表 | 客服 |
| `get_order_detail` | 订单详情 | 客服 |
| `check_return_eligibility` | 判定能否退换 | 客服 |
| `create_refund_request` | 创建退款申请 | 客服 |
| `get_sales_insight` | 销售洞察（滞销/爆款） | 运营 |
| `update_product_copy` | 写回商品文案 | 运营 |

### 5.3 降级策略

- 配置了 `AI_BASE_URL` + `AI_API_KEY`：走 OpenAI 兼容 `/v1/chat/completions`，支持 tool calling。
- 未配置 / 请求失败：自动降级到本地规则引擎（意图分类 + 关键词检索 + 模板应答），保证全流程可演示。
- 降级状态在 UI 上以"本地模式"标签明示，不欺骗用户。

## 6. 非功能要求

- 首屏 < 1.5s（本地）
- 接口 P95 < 200ms（不含 AI）
- AI 首字节 < 2s（真模型）/ < 300ms（本地引擎）
- 所有写操作幂等键防止重复下单
- 密码 bcrypt 哈希，JWT 鉴权，角色越权返回 403

## 7. 验收标准（Demo 级）

1. 空库启动自动 seed，C 端可见 ≥ 12 个商品
2. 可完成「浏览 → 加购 → 下单 → 查看订单」全链路
3. C 端 AI 客服问"我上一个订单到哪了"能返回真实订单数据
4. C 端 AI 客服能对符合条件的订单发起退款并落库
5. B 端可新增商品、发货、审核退款
6. B 端 AI 一键生成商品文案并写回
7. 测试用例全部通过
